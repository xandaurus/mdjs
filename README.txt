Эмулятор Mega Drive / Genesis (MDJS) — офлайн-версия

Автор и разработчик: Александр Орёл

КАК ЗАПУСТИТЬ
Откройте файл index.html двойным кликом (Chrome, Edge, Firefox, Safari на компьютере; Chrome на Android).
Интернет и сервер не нужны. Нажмите «Выберите ROM файл» и выберите свой ROM (или перетащите файл на страницу).
ROM в папку не входит и никуда не отправляется. Папку mdjs-emulator целиком можно переносить на флешку/другой компьютер.

УПРАВЛЕНИЕ
Стрелки — движение; Z / X / C — A / B / C; Enter — Start; P — пауза; F5 / F8 — сохранить / загрузить состояние;
F — полный экран (выход — Esc); M — звук. Поддерживаются геймпад и сенсорные кнопки (на телефоне появляются сами).

СТРУКТУРА ФАЙЛОВ (подключаются тегами <script src> по порядку, как в index.html)
index.html              — страница
css/style.css           — стили
js/util.js              — общее состояние, вспомогательные функции
js/cpu-m68k.js          — процессор Motorola 68000
js/cpu-z80.js           — процессор Z80
js/vdp.js               — видеочип
js/ym2612.js            — FM-синтезатор YM2612
js/psg.js               — звуковой чип PSG
js/sound.js             — звуковая подсистема (Z80 + YM2612 + PSG)
js/genesis.js           — консоль: память, ввод-вывод, DMA, кадр, регионы PAL/NTSC
js/state.js             — быстрые сохранения
js/present.js           — вывод кадра на экран
js/audio-fallback.js    — запасной звук (ScriptProcessor)
js/audio-worklet.js     — звуковой поток AudioWorklet
js/input-keys.js        — клавиатура и геймпад
js/input-touch.js       — сенсорные кнопки, скользящая крестовина, запрет меню копирования
js/fullscreen.js        — полноэкранный режим
js/emu-worker.js        — код Web Worker: вся эмуляция работает в отдельном потоке
js/worker-host.js       — главная сторона воркера: сборка воркера из файлов ядра
js/app.js               — загрузка ROM, кнопки, связь с воркером (или главный цикл, если воркер недоступен)
tests/browser_test.py   — автотест в Chromium (нужен Playwright и ROM: ROM=файл python3 tests/browser_test.py)

ПРИМЕЧАНИЯ
- Вывод картинки по умолчанию 2D. Для проверки WebGL откройте index.html?gl=1 (или http://.../?gl=1); при отсутствии WebGL остаётся 2D.
- Эмуляция по умолчанию идёт в Web Worker (звук напрямую в AudioWorklet): интерфейс и звук не мешают друг другу.
  Если браузер воркер не запустил, всё работает как раньше на главном потоке. Принудительно главный поток: window.MD_NO_WORKER = true.
- Файлы используют общее пространство имён MD, поэтому порядок подключения в index.html менять нельзя.
- Совместимость с играми не гарантируется: эмулятор проверялся на одной игре. Не реализованы сохранения SRAM,
  банкование больших картриджей, 6-кнопочный геймпад, режимы «тень/подсветка», чересстрочный режим, SSG-EG.
- На iPhone Safari обычно не запускает скрипты из локального HTML в «Файлах»; там нужна версия по адресу (GitHub Pages).

Быстрый процессор (экспериментально)
  Селектор «Процессор» в панели управления. По умолчанию — обычный. Быстрый режим
  ускоряет циклы ожидания 68000 (tst.b (abs).l / beq|bne.s -8) без изменения результата.
  Проверка идентичности: ROM=... node tests/lockstep_fastcpu.mjs 1500 (сравнение регистров,
  циклов, RAM, VRAM, кадра и звука) ; замер: node tests/lockstep_fastcpu.mjs 1200 bench

Фильтры
  Кнопка «Фильтры» в панели управления: строки развёртки (scanlines), сглаживание (bilinear),
  VHS эффект. Можно включать по отдельности и вместе; выбор запоминается. Только визуальное
  наложение (CSS), на эмуляцию и звук не влияет. Тест: ROM=... python3 tests/filters_test.py <папка>
